# SajArt — site vitrine

Prototype React (Vite) pour l'atelier SajArt à Ségou, Mali.

## Lancer le projet

```
npm install
npm run dev
```

Puis ouvrez l'URL affichée dans le terminal (en général http://localhost:5173).

## Structure

- `src/components/` — un composant par section (Header, Hero, About, Services, Gallery, Contact, Footer)
- `src/data/content.jsx` — textes des services et de la galerie
- `src/styles/tokens.css` — couleurs et polices : modifiez ce fichier pour ajuster toute la charte graphique
- `src/styles/global.css` — le reste des styles
